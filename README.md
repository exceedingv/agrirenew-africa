## Tesler Nig LTD site

`tesler-nig/index.html` is a standalone website for Tesler Nig LTD, a Nigerian software company. It is a single HTML file with no build step: open it in a browser or serve the repo with any static host (for GitHub Pages it is served at `/tesler-nig/`).

Before going live, replace the placeholder contact email (`hello@teslernig.com`, in the Contact section) with the company's real address.
