# Partner logos

Put logo files here that you have written permission to use, named after the badge text in lower case, as PNG:

- dbn.png, cac.png, fmafs.png, nafdac.png, ngx.png
- g.png (Google), aws.png, at.png (atingi)

A missing file shows the text badge instead. Transparent PNGs about 200px tall work best.
